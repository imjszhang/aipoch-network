# Reviewed public-source pilot observations

`snapshots.json` is the fixed offline build input. Its baseline 21 repositories and 19 distinct GitHub accounts were checked on 2026-09-15; two additions observed on 2026-09-17 are documented below. each source and each metric retains its own actual observation time. The batch time is the end of collection, not a claim that every field was checked simultaneously. The reviewed whitelist includes repository metadata, public counters, default-branch HEAD observations and account counts. It excludes credentials, raw responses, follower identities, emails and full READMEs. It is not a live status guarantee or evidence of upstream participation/endorsement.

Live refresh writes ignored `.cache/` inputs. Offline CI explicitly selects this fixture with `SOURCE_BATCH=fixtures/pilot/snapshots.json`. Use the reviewed `.cache/refresh-state.json` projection for fixture updates; validate it and preserve stable identities before committing. Do not copy arbitrary `.cache/batch.json` content or relabel retained observations as fresh. Production still requires a new trusted refresh, reviewed candidate and separately authorized deployment.

The original 21 sources are SciPy, scikit-learn, Jupyter Notebook, Biopython, Snakemake, NumPy, pandas, Matplotlib, seaborn, Xarray, Scanpy, AnnData, Astropy, Nilearn, NiBabel, MNE-Python, Statsmodels, SymPy, NetworkX, scikit-image and MuData. In that baseline, eighteen accounts are organizations and one is personal; scverse's three repositories share one account observation. Organization and Actor projections share identity. SciPy has software and a fixed-path documentation resource; Scanpy retains its reviewed AnnData evidence relationship. All classifications and fixed references are maintained in the registry.

GitHub's public user response may mask private-profile counts to zero. Counts are therefore labelled publicly reported, not guaranteed complete totals. Unsupported organization Following remains absent. Synthetic edge fixtures cover failures, missing fields, private sources, identity changes and rate limits without modifying upstream projects.

The 2026-09-15 implementation refresh observed Stars/Forks and valid default-branch committer dates for all 21 sources, and public follower counts for all 19 accounts. Snakemake's large single-commit response exceeded the existing 512,000-byte limit; the collector now uses a one-item commit list that omits patch bodies. Only that source was retried after the endpoint fix; other observation timestamps were preserved. See [probe and backfill evidence](../../docs/verification/explore-dates-metrics/README.md). Historical publication dates are independently maintained in `registry/publication-ledger.json`, never inferred from this fixture's batch time.

The earlier 2026-09-12 observations and 2026-09-14 MuData-only addition remain in Git history. The current refresh replaces them with actual new observations rather than changing old timestamps in place. Descriptions and code remain subject to the upstream projects' own terms. Ordinary contributors still only need to submit a public URL; they do not need to create fixture data. See the [maintainer guide](../../docs/maintainer-guide.md).
