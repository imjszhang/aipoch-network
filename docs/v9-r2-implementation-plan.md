## 3. 用户体验的固定结果

### 3.1 未连接的公共网络

- 首页显示 Science / Open to All、Join 主入口、Open-Science 产品卡、搜索、带数量五格及公共内容分区。
- 浏览、搜索、筛选、排序、分页、阅读来源、协作跳转和公开推荐始终可用。
- 隐藏 Save/Unsave、Saved、Recently viewed 和个人库清理入口；事件处理器也拒绝未连接的个人数据修改，不新增浏览记录。
- 项目显示 Connect to open，能力显示 Connect to use。选中对象后展开连接流程，不改变目录筛选、页码、滚动或选择。
- Get Open-Science 全部指向 `https://aipoch.com/open-science`。打开该页面不表示检测到客户端或连接成功。

### 3.2 已连接的个人首页

- 首页整体切为 Welcome back，保留 Explore、Share your research，以及 Your feed / Your projects / Saved / Following / Contributions。
- Your feed 展示待续对象、Recently viewed 和 Reference receipts；Saved 使用本浏览器保存的有效目录条目。
- Your projects、Following、Contributions 没有真实 Connector 数据时展示明确空状态；公共目录不得冒充个人项目，推荐草稿不得冒充已发布贡献。
- 状态使用小绿点、灰色 Open-Science connected 和淡色 Demo。不用黄色条幅；演示标识在演示期间持续可见。
- Disconnect 恢复公共首页。若断开时位于目录或详情，则保留当前页面与筛选；收藏和选择保留，旧发送资格失效。

### 3.3 精简浮窗与完整审阅

- 未连接浮窗：简短说明、文字状态、Connect Open-Science、Get Open-Science。
- 已连接浮窗：状态、Your research home、Disconnect。
- 有待续对象时追加一行对象名称与 Continue。无嵌套说明卡、库标签、回执列表或重复主操作。
- 完整引用审阅、替换确认和发送反馈使用独立空间。每个页面保留清晰的主要工作台操作，相关卡片不堆叠等权重黑色按钮。
- 全站无独立 Open Open-Science 按钮。项目 Open in Open-Science、能力 Use in Open-Science 仍然保留；Continue in Open-Science 必须带具体对象上下文，不表示启动应用成功。

### 4.1 导航与静态正文

当前 Link 是普通 `<a>`，切页会整页加载。新增浏览器内导航，保持共享会话不因普通站内点击重建；静态 HTML 继续支持直接访问、刷新、搜索引擎和加载失败时阅读。

只接管站内、同源、同 base 的普通导航点击。保留外链、下载、修饰键、新标签页、页内锚点与原生表单语义；后退/前进恢复 URL 对应的查询、筛选、排序和分页。更新页面标题、主要焦点与历史滚动位置。连接面板开关不新增无意义历史记录。

新增 `/join/`、`/me/`，并将 `/contribute/` 映射为设计的贡献说明/既有公开推荐入口，记录最终路径决定。旧 `/me/` 未连接为连接入口，已连接进入首页 Saved。个人首页视图用可恢复的 URL 或导航状态表达，但 URL 不能赋予连接或发送资格。保留既有资源 ID、tombstone 双路由与替代链接。

### 4.2 首屏子集与完整目录

当前首页和详情由 `pageDataForRoute` 注入显示子图；部分目录页面从共享 catalog 加载后 hydration。直接把子图当全目录，会导致个人收藏、站内跳转和统计错误。

实现统一目录读取层：先用首屏子图保持静态内容与首次 hydration 一致，进入目录/个人库或解析其他对象时按需加载完整目录。沿用读取上限、超时、结构校验、快照一致性与失败重试。当前页面与新目录快照不一致时保留可读旧内容并提供明确刷新路径，不混用版本建立引用。

数量来自全量统计；来源引用从完整对象解析。完整目录尚未加载时区分“加载中/加载失败”和“对象确实缺失”，避免误报撤回或清空收藏。单页不重复内嵌全目录，不破坏已有体积控制。

### 4.3 连接适配与模式隔离

状态包括 Not connected、Connecting、Connected、Not confirmed、Interrupted；attempt ID、session ID 与所有等待归状态层所有。适配接口只表达连接/取消/断开/发送/回执/中断所需能力，不定义正式 Connector 线协议。

- 默认生产构建使用 unavailable 适配器。点击 Connect 后如实说明当前无法确认连接；不推断未安装，并保留重试、继续浏览、获取客户端和手工引用。
- 单独预览构建启用 Demo，正常页的连接按钮即可走完整演示，无需先进入 Review。演示标识不可隐藏；不得由生产 URL 参数开启模拟成功。
- Review 场景仅存在于演示构建，提供手动响应、无响应、失败、迟到和错误回执等控制。普通演示域与 Review 临时域分开；切换/退出/复位注销旧等待和回调，不恢复 Sending。
- 进入 Review 不覆盖普通域会话与收藏。退出时只恢复仍有效的普通会话，并重新检查其有效性；过期连接、旧审阅资格及已失效请求不能复活。临时域的响应设置和回执不影响普通域。
- 模式在应用挂载前确定并与预生成的初始页面一致。构建验证默认产物不会启用 Demo；两种构建都不能读写 Open-Science 源码或服务。
- 真实 Connector 后续实现可信握手、兼容协商、传输和恢复验证后，替换适配器并重新跑同一行为契约测试。

### 4.4 引用、同意与回执

构建内部研究引用模型，包含稳定对象/类型、Open 或 Use 动作、公开位置、目录快照依据、全部来源、完整适用版本/路径、许可与条件；未知、未固定和不适用必须可区分。内部 JSON 不是正式 Connector schema，短 SHA 不能替代完整版本。

审阅资格绑定本次有效会话和实际展示的准确内容。对象、动作、来源、版本、许可、条件、快照或会话改变时重新解析并要求确认；不能只更新一句提示而继续发送旧内容。撤回/缺失对象禁止发送，归档/未知许可等按真实状态说明，不擅自升级为验证成功或补造元数据。

Sending 期间禁重复发送；新对象进入时明确选择继续等待或替换。回执同时匹配请求、有效会话、对象和准确内容；错误、重复、迟到、旧域或已取消响应均不能新增成功。停止等待不表示远端撤回；超时不证明未送达；每次重试都需用户明确操作，不自动恢复或重发。

生产无法传输时，提供可阅读、复制或手工选择的准确引用及来源链接，复制失败仍保留完整文本。浏览器弹窗、时间经过、焦点返回和 toast 都不是成功证据。

### 4.5 本机数据和可访问性

持久化收藏、最近浏览、说明语言及可恢复选择；连接、审阅资格和在途请求不持久化为有效状态。完整刷新、新标签页重新确认连接；恢复选择前检查稳定 ID 与最新可用目录。历史回执不能当作仍连接，Demo 回执不得跨成真实记录。

存储结构带版本并做解析校验；损坏、禁止写入、空间不足时降级内存并提示，保留可恢复旧数据。说明语言不受连接限制。不同模式使用独立命名空间，Review 复位不删除普通收藏；多标签页同步收藏不授予会话资格。

对话框进入焦点、焦点约束、Esc 和返回触发点统一实现。停止等待与关闭展示分开表达，不因关闭面板悄悄撤销请求。异步状态用可读文字和 live region，移动端有可触达控件，减少动效与 200% 放大不妨碍主要操作。

### 7.2 检查命令与构建隔离

以下是实施后要执行的命令，计划阶段不运行产品测试。沿用 `.node-version` 的 Node 24.18.1 和锁定依赖；`npm ci` 仅在准备干净验证环境时运行。

1. `npm run typecheck`。
2. `npm test`：N1/N4 将新增 `web/tests` 纳入现有测试脚本，默认无客户端、无凭据。现有契约/流水线/消费者测试继续保留。
3. `SOURCE_BATCH=fixtures/pilot/snapshots.json SITE_BASE=/ npm run build`。
4. `TEST_BASE=/ npm run test:e2e`，针对本次产物启动新服务，避免复用旧预览造成假通过。
5. `SOURCE_BATCH=fixtures/pilot/snapshots.json SITE_BASE=/aipoch-network/ npm run build`。
6. `TEST_BASE=/aipoch-network/ npm run test:e2e`，同样使用对应产物与新服务。根路径报告须在覆盖产物前保存。
7. N1-03 新增并记录独立 Demo 构建/测试入口，对两种 base 跑连接与 Review 场景；报告必须注明 Demo。入口和输出路径在实施时确定，不能把尚不存在的命令写成已运行。
8. 验证默认构建的 unavailable 行为、模式开关不可由 URL 注入，以及无脚本/目录加载失败正文回退。

当前 `scripts/build.ts` CLI 默认切换 `dist`，外层仅设 `BUILD_OUTPUT` 不会改变其目标；如为 Demo/根路径/子路径并存扩展输出参数，保留 staging、校验、锁及原子切换，不绕过构建器直接覆盖。现有 CI 可复用；增加前端状态与模式验证不增加发布权限。

记录新产物与基线的 JS、图片、总字节和加载请求差异，检查新增产品素材与导航不会让每页重复内嵌全目录。只有出现实际规模回退或读取策略改变时扩展规模测量，不机械重复无关采集演练。
