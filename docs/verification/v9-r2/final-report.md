2026-09-13。本版已在 `aipoch-network` 完成本轮设计实现与本地候选交付。232 项离线测试和 352 项浏览器检查通过。**按用户最新指示停止旁白专项，不以其未测部分阻塞本轮交付；未提交、推送、运行远端 CI 或部署生产。** 完整读屏验收不列为通过。

## 交付结果

公共首页、数字分类入口、指定 Logo、目录搜索与筛选、项目行和能力卡、详情来源、社区活动和独立贡献页按最新 v9-r2 整合。已连接后整体替换为个人首页；浮窗精简；未连接时隐藏并守卫 Save 等个人操作。

工作台具有独立状态和适配边界：保留对象上下文，审阅准确引用，显式确认后发送，严格匹配回执，处理取消、超时、替换、失效和存储降级。默认正式构建如实显示连接不可确认；单独 Demo 可演示完整流程，不代表真实客户端连接或执行。

公开推荐显示准确目标与完整草稿，修改内容使确认失效，外部草稿打开新标签以保留本页；长文和复制拒绝均有回退。GitHub 授权、导入和执行继续归未来 Connector，网站保持独立静态目录。
