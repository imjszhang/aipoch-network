# 实施记录与剩余验收

更新：2026-09-12。目标仍是完成完整实施计划。当前为**可运行并完成主要技术验收的私有候选**，未宣布全项目完成或公开发布。37 项任务、23 个验收场景全部保留。

## 已核验的结果

- 独立 Node 24 / TypeScript / React / Vite 项目，精确依赖及锁文件已固定。网站、契约、测试、消费者与发布候选不依赖 Open-Science。
- 20 个真实公开科研来源均完成实际采集。包含组织和个人、同组织多个仓库、同仓库多资源、Scanpy/AnnData 跨仓库项目及带证据关系、SciPy 固定文档路径。
- v1 公共清单、按记录数与 4 MB 双重分片、内容摘要、历史快照、最小撤回台账以及纯 Node 独立消费者已实现。完整 README 不进入公共产物。
- 接通可选增强、编辑覆盖、固定 commit/path、关系、访问条件、运行说明、认领与组织精确策展范围。信息不足保持未知，未声称真实组织授权或科学验证。
- 来源全失败、部分失败、限流、身份复用、私有化、源撤回、授权失效、过期数据、旧版本恢复均有回归。负面状态逐条保存，普通构建/恢复也应用最新状态；清理候选与正常刷新分开标记。
- 最近完整本地检查：类型检查、**179 个离线测试**、93 个静态页面及全部产物链接验证通过。本地候选 `26b7d31efa5dd84150f48a9c`，总计 2,329,116 字节。观察时间来自实际来源批次，不伪装为构建时间。
- 根路径与 `/aipoch-network/` 各 **40/40** 浏览器场景通过，无失败、跳过或重试。覆盖桌面/Pixel 7 模拟、匿名与无 JS 浏览、目录/索引加载失败重试、固定路径、关系双向跳转、组织多来源、研究者、认领范围、撤回双路由、访问条件、投稿重新审核、中文长草稿、200% 文字与局部溢出。详细证据见 [浏览器报告](verification/browser-verification.md)。报告冻结于 `1e5c724017c15008ee05708b`；其后改动为公共 README 排除、字节分片和输出预算，UI 代码及资产未变，最终提交的远端检查另行记录。
- 完整 100 / 1,000 / 10,000 条规模均实际构建并逐页校验；10,000 条有 10,015 页，171.88 MB，约 29 秒；首次搜索全部请求文件的 gzip 等价总计 1.35 MB。原 100 MB 对 10,000 条未达，已记录优化与 250 MB 构建硬上限校准，见 [规模报告](verification/full-site-benchmark.md) 与 ADR-017。
- 已推送实现基线 `d498975` 的 [GitHub CI](https://github.com/imjszhang/aipoch-network/actions/runs/34688078703) 在独立 Ubuntu runner 通过安装、离线测试、静态构建和 Chromium。后续改动的最终 SHA / CI / main 刷新恢复演练待本轮推送后补录。
- 仓库最近实际查询为私有、`has_pages=false`。账户 `plan=null` 表示套餐未知；未确认私有源仓库 Pages 资格。

原始 v6 HTML 未被执行；前端依照其静态提取的结构、布局、样式和交互意图实现。当前实现截图已归档，不能把它们写成参考原件已进行同视口运行对比。原件 SHA-256 保持 `4adb13887c17306c798ef94ccc53d62d314c05fb01e359f214a8c0db259b552a`。
