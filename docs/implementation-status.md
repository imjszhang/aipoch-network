## 已核验的结果

- 独立 Node 24 / TypeScript / React / Vite 项目，精确依赖及锁文件已固定。网站、契约、测试、消费者与发布候选不依赖 Open-Science。
- 20 个真实公开科研来源均完成实际采集。包含组织和个人、同组织多个仓库、同仓库多资源、Scanpy/AnnData 跨仓库项目及带证据关系、SciPy 固定文档路径。
- v1 公共清单、按记录数与 4 MB 双重分片、内容摘要、历史快照、最小撤回台账以及纯 Node 独立消费者已实现。完整 README 不进入公共产物。
- 接通可选增强、编辑覆盖、固定 commit/path、关系、访问条件、运行说明、认领与组织精确策展范围。信息不足保持未知，未声称真实组织授权或科学验证。
- 来源全失败、部分失败、限流、身份复用、私有化、源撤回、授权失效、过期数据、旧版本恢复均有回归。负面状态逐条保存，普通构建/恢复也应用最新状态；清理候选与正常刷新分开标记。
- 最近完整本地检查：类型检查、**201 个离线测试**、93 个静态页面及全部产物链接验证通过。使用固定 pilot 输入的本地候选 `26b7d31efa5dd84150f48a9c` 含 113 文件，总计 2,454,028 字节，已包含完整第三方声明。观察时间来自实际来源批次，不伪装为构建时间；下文 179 项及先前包大小是对应历史提交的真实记录。
- 根路径与 `/aipoch-network/` 各 **40/40** 浏览器场景通过，无失败、跳过或重试。覆盖桌面/Pixel 7 模拟、匿名与无 JS 浏览、目录/索引加载失败重试、固定路径、关系双向跳转、组织多来源、研究者、认领范围、撤回双路由、访问条件、投稿重新审核、中文长草稿、200% 文字与局部溢出。详细证据见 [浏览器报告](verification/browser-verification.md)。本地截图报告冻结于 `1e5c724017c15008ee05708b`；11 个记录的源码摘要与最终实现一致。最终实现及合入 main 后的 CI 均重新通过两种基路径的全部检查。
- 完整 100 / 1,000 / 10,000 条规模均实际构建并逐页校验；10,000 条有 10,015 页，171.88 MB，约 29 秒；首次搜索全部请求文件的 gzip 等价总计 1.35 MB。原 100 MB 对 10,000 条未达，已记录优化与 250 MB 构建硬上限校准，见 [规模报告](verification/full-site-benchmark.md) 与 ADR-017。
- 实现提交 `214b7aadf2226be53c2c17c519708916d3095ba7` 经 [PR #1](https://github.com/imjszhang/aipoch-network/pull/1) 合入私有 main，集成提交为 `12bea89004d8a68ea96858d9abc4f1999084f021`。[实现 CI](https://github.com/imjszhang/aipoch-network/actions/runs/34689980610) 与 [main CI](https://github.com/imjszhang/aipoch-network/actions/runs/34690269444) 均在干净 Ubuntu runner 通过安装、类型、179 个离线测试、静态构建及两种路径的 Chromium 验证。
- 两次真实受信 main 刷新均成功：第一次 20 个来源全部可访问；第二次恢复第一次的观察状态、负面台账和经过校验的公共历史，再成功检查全部 20 个来源。最新候选 `35dd0c46df11b75e7963601f` 含 93 页、122 文件、2,467,214 字节；前一次快照的全部文件保持字节不变。独立消费者通过 HTTP 读取当前、历史及固定资源版本。完整记录见 [私有集成验收](verification/private-integration.md)。
- GitHub main 的三个 Issue Forms 与配置文件通过只读 Contents API 与本地 Git blob 一致性核对。未代替用户投稿，也未把模板存在称为外部账号投稿成功。
- 实现提交的 5 个可达提交、167 个历史 blob 与本地候选完成有限模式扫描；未命中 GitHub 令牌、私钥或 AWS key ID 模式。凭据 URL 命中来自负向测试；历史规划文档含本机路径，设计原件仍在私有 Git 历史。此扫描不代表完整许可或安全审计。
- 仓库最近实际查询为私有、`has_pages=false`。账户 `plan=null` 表示套餐未知；未确认私有源仓库 Pages 资格。
- 私有交接收尾增加了运行尝试级恢复、精确事件提交与子路径候选选择、实际浏览器依赖声明、[新增来源维护演练](verification/source-intake-handoff.md)及[未启用的 Pages 发布材料](deployment/README.md)。恢复新增 11 项、依赖声明 4 项、候选校验 7 项回归均包含在上述 201 项中。具体发布配置仍只存在于 `docs/`，不是已启用工作流。
- 后续 [PR #2](https://github.com/imjszhang/aipoch-network/pull/2) 和 [PR #3](https://github.com/imjszhang/aipoch-network/pull/3) 已合入私有 main。确切提交 `6e13ce09ddab7152454cfc77ffc58161609cf51e` 的 [CI](https://github.com/imjszhang/aipoch-network/actions/runs/34692675521) 与[真实子路径刷新](https://github.com/imjszhang/aipoch-network/actions/runs/34692686489)均成功。新候选 `bc96aa6bab0aa21b899841b3` 有 93 页、133 文件、2,637,535 字节；独立两次下载、完整文件树核验及 HTTP 消费通过。此前两份快照的 20 文件保持原字节。一次真实刷新中的测试环境问题、失败 artifact 边界、修复及后继恢复均如实保留于[私有交接验收](verification/private-handoff.md)。该候选和核验有明确时效，后续 main 变化或到期需重新刷新；记录不是持续发布授权。

原始 v6 HTML 未被执行；前端依照其静态提取的结构、布局、样式和交互意图实现。当前实现截图已归档，不能把它们写成参考原件已进行同视口运行对比。原件 SHA-256 保持 `4adb13887c17306c798ef94ccc53d62d314c05fb01e359f214a8c0db259b552a`。

已上线的根域 HTTPS 网站及公开目录可独立使用，首次部署证据见 [公开部署记录](deployment/public-pages.md)。剩余项目要求包括：外部普通账号投稿及审核闭环、设计原件分发审查、A22 同视口设计对照，以及生产故障恢复交接。A23 在收到新版设计时执行，当前没有新版 HTML，不将此条件当作已发生的升级。
