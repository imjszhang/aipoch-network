# 实施记录与剩余验收

更新：2026-09-12。目标仍是完成完整实施计划。当前为私有开发中的可运行版本，**尚未宣布项目完成或公开发布**。

## 已核验的当前结果

- 独立 Node 24 / TypeScript / React / Vite 项目，依赖版本与锁文件已固定。
- 5 个真实公开科研仓库完成读取；离线试点只保存筛选后的公开元数据，完整响应和 README 缓存在 `.cache/`。
- 已生成独立 v1 清单、分片、摘要和网站搜索数据；公共契约消费者仅使用 Node 内置模块。
- 首版网站已实现首页、目录搜索、项目/能力/组织/集合/来源页面、三步投稿草稿；后续增加研究者及撤回页面。
- 已完成根路径与 `/aipoch-network/` 子路径的真实静态构建、桌面及移动 Chrome 浏览器检查。每种路径 12 个场景通过，包括匿名浏览、搜索筛选、详情刷新、真实 404、键盘入口、搜索失败和投稿预览。
- 已验证目录构建和网站构建失败时保留上次完整输出；不可信来源、别名、限流、转私有、撤回、兼容读取和中文搜索有离线回归测试。
- GitHub API 当前确认仓库仍为私有，`has_pages=false`。账户 API 未提供套餐信息（`plan=null`），不能据此确认私有源仓库的 Pages 资格。

上述浏览器检查使用本机 Chrome；Playwright 固定 Chromium 下载与 CI 环境核验另行记录。截图位于运行生成的 `test-results/`；它们不作为参考 HTML 已被逐像素比对的证明。
