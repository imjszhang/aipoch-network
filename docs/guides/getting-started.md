# Find single-cell analysis resources with AIPOCH Network

Resource introduction. Original review: September 14, 2026; English adaptation: September 16, 2026.

Write down your data and question first. For example: “I have a single-cell expression matrix and want to understand how cell and gene annotations relate to it.”

1. Open [AIPOCH Network](https://aipoch.network/) and browse or search for AnnData and Scanpy. Public browsing does not require sign-in or an installed workbench.
2. Read the entry's source, purpose, and information date. AnnData and Scanpy have different roles; similar names or related workflows do not make resources interchangeable.
3. Follow the source link upstream. The [AnnData introduction](https://anndata.readthedocs.io/en/stable/tutorials/notebooks/getting-started.html) explains matrices and their annotations. Check installation and execution requirements against upstream documentation and your environment; this guide does not supply a tested environment.
4. Record the resource URL, the version you actually select, and its intended use. List missing inputs or explanations before adding another model.

The September 14 review confirmed AnnData, Scanpy, and [MuData](https://aipoch.network/capabilities/resource~mudata-library/) in the catalog. The other nine tools discussed in the [main guide](python-single-cell.md) were research candidates at that time. Follow upstream links when a catalog entry is absent; absence is not evidence of inclusion.

To propose a resource, use the [contribution guide](../../CONTRIBUTING.md). A public GitHub URL is enough to start candidate review. Submitting an issue requires a GitHub account; generating a draft on the website does not submit it.

These steps cover finding and understanding resources. They do not connect a client, install software, execute research, or produce an analysis-completion receipt.
